# Jordan Taylor study persona

Jordan is a resettable test participant account shared through Supabase. Put the three server-only values in ignored `study.secrets.local`, then run `npm run study:jordan -- provision`. Between participants, run `npm run study:jordan -- reset`.

The AI app itself receives only the public Supabase URL and anon key in `.env`. Sign in to it as Jordan to load the same data. The fixture intentionally leaves the $850 paycheck, Moving Fund, $300 existing cash, $28 grocery transaction, and Friend Outings unfinished for participants.
