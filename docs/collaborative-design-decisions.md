# Human + AI Collaborative Design Decisions

| Origin | Decision | Final result |
| --- | --- | --- |
| Human | Coastal harbor identity, warm palette, Scuttle mascot, existing functional base | Preserved as the visual personality and data foundation. |
| AI proposal, approved by human | A single “Safe to Spend” hero and brief radar reduce dashboard scanning effort | Implemented with account cash less still-unspent active budget commitments; allocations never become account withdrawals. |
| Joint refinement | Guided paycheck planning should be faster but retain exact category control | Quick Plan groups existing allocations; Detailed Plan shows the same records without duplication. |
| AI proposal, approved by human | Reallocation should show a plain-language review before it changes a plan | Move Money previews source, destination, amount, and no-account-impact statement. |
| Joint refinement | Encouragement should be supportive but unobtrusive | Scuttle appears in small contextual cards and follows existing reduced-motion behavior. |

All research tasks remain available through the original functional flows: paychecks, categories, transactions, subscriptions, goals, and history.
