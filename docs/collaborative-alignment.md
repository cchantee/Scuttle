# Collaborative interface alignment

The collaborative condition adopts the human interface’s functional UX refinements while retaining its own navy, sea-glass, sand palette and system typography. No human-only or AI-only files were edited.

- Home prioritizes a current-paycheck navy balance card, allocation progress, a small account summary, payday, one reminder entry, and three budget previews. Insights remains available without a large coaching panel.
- Paychecks hides previous/planned entries behind a button. Navbar and Home open the same current plan.
- Transactions returns to the list after save and defaults to This paycheck. All exposes historical activity; Bills are distinct from subscription reminders.
- Search covers records, amounts, dates, notes, linked accounts/categories, and pages including Insights and payday settings.
- Bills & reminders has its own page and entry points on Home, Settings, and paycheck details. Receipt alerts list due reminders without posting charges.
- Goals include compact Reserved/Saved contribution cards, Confirm saved / Move money actions, and creating a goal from Add to goal.
- Financial history has search, filters, record destinations, and totals that exclude transfers/plans from spending.
- Loading uses snapping claws and moving watercolor waves with reduced-motion support. The walkthrough has six steps.

Validation: TypeScript; 145 domain/workflow tests; iOS bundle; browser phone viewport checks using isolated fictional local data with Supabase disabled. Checked search, receipt popup, transaction save/default date and scope, All history, goal creation access, and editable payday. No live account data, fixture, credentials, reset behavior, or bank calculations changed.
